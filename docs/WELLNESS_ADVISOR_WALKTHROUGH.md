# Wellness Advisor — Code Walkthrough

## What this feature does

The Wellness Advisor shows a short summary of the signed-in user's recorded habit activity over the last 30 days and displays up to three practical suggestions. The suggestions are generated by ordinary Python rules, not by an AI model or an external service.

## How the data flows

1. `views/dashboard_window.py` opens `WellnessView` and passes the authenticated user's record to it.
2. `views/wellness_view.py` reads that user's `user_id` and asks `ProgressController` for a report.
3. `controllers/progress_controller.py` passes the request to `ProgressRepository`.
4. `repositories/progress_repository.py` queries only habits belonging to that `user_id` and summarizes the last 30 days of completion records.
5. `services/wellness_advisor.py` reads the returned totals and per-habit rows and selects suggestions using transparent `if` conditions.
6. The Wellness screen displays the report summary and suggestions. Refresh Suggestions reloads the report so changed tracking data can influence the advice.

## Rules used

- **No habits:** suggest starting with one realistic habit.
- **Habits exist, but no recorded habit-days:** explain how to start tracking.
- **Fewer than three recorded habit-days:** recommend collecting more observations before interpreting a pattern.
- **At least three recorded habit-days and an overall completion rate of 80% or higher:** recognize consistency and encourage maintaining a manageable routine.
- **Overall completion rate below 50%:** suggest making one habit smaller or choosing a more convenient time.
- **A habit has at least three recorded days and less than 50% completion:** show an additional suggestion naming that habit.
- **Category balance:** suggest reviewing the routine when all current habits use one category.

Only the first three resulting recommendations are displayed. The logic uses existing report fields; it does not create a database table or change the database schema.

## How to explain it during a defense

> “The Wellness Advisor is a rule-based feature. It retrieves the user's own last-30-days habit report and uses simple conditions to choose suggestions. For example, it asks a user with no records to start tracking. If a habit has been recorded on several days but has a low completion rate, it suggests reducing the task or changing its timing. The rules are readable and testable, and all data stays within the existing MySQL-backed application.”

## What to test

- No habits produces a start-a-habit suggestion.
- Habits without tracked days produce a tracking suggestion.
- High recorded completion produces a positive consistency suggestion.
- Low per-habit completion can produce advice that names the habit.
- Pressing **Refresh Suggestions** reads the latest report again.
- If MySQL is unavailable, the screen displays a recovery message instead of attempting to invent a personalized result.

The output is general habit-building guidance and is not medical advice.
